
# 🚨 PIR Motion Detection Security System

A simple Arduino-based security system that uses a PIR (Passive Infrared) sensor to detect human motion. When motion is detected, the system activates an LED and buzzer to provide an alert. This project demonstrates the basic concept of motion detection and security systems.

## 🔧 Components Used
- Arduino Uno
- PIR Motion Sensor
- Buzzer
- LED
- 220Ω Resistor
- Breadboard
- Jumper Wires

## ⚙️ Working
The PIR sensor continuously monitors the surrounding area for movement. When motion is detected, it sends a signal to the Arduino. The Arduino then turns ON the LED and buzzer, indicating a possible intrusion.

## ✨ Features
- Real-time motion detection
- LED and buzzer alert
- Simple and low-cost setup
- Easy to build and understand
- Simulated using Tinkercad

## 🎯 Applications
- Home security systems
- Room monitoring
- Intrusion detection
- Basic automation projects
